# YuE2 Console

Local, GPU-powered song-composer web app built around the YuE2 model.

This repo currently contains an **interactive prototype** and the **development roadmap**; the real backend/model integration has not been built yet.

- `prototype/yue2_console.html` — open in any browser to preview the planned UI/UX (bilingual EN/VI, mock data — no real model wired up yet).
- `AGENTS.md` — task checklist for building the real backend/frontend. Any AI agent or engineer picking up this project should read it first and use the prototype as the UX reference / acceptance criteria.

Inspired by [Ladypoly/YuE2_WebUI](https://github.com/Ladypoly/YuE2_WebUI) and the [YuE2 model](https://github.com/multimodal-art-projection/YuE).
